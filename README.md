Every story happened or was first reported on that day, with sources (BBC, Reuters, The Guardian, CNBC, MercoPress, One Turn) printed on the image.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to `out/entry.png`. The image itself is drawn by `draw_poster.py` (run `python3 draw_poster.py` to regenerate it).
